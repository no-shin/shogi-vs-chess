# 将棋対チェス AI（ブラウザ版）

将棋ったーの「将棋対チェス」ルール（先手＝将棋、後手＝チェス）で AI と対局できるページです。
サーバは使わず、AI（NNUE 評価＋αβ探索）は WebAssembly でブラウザの中で動きます（1 スレッド。PC の速さで強さが変わります）。

- `index.html` 対局画面、`worker.js` ブラウザ内の対局サーバ役、`engine.js` / `engine.wasm` ルールと探索、`nnue.bin` 評価ネット
- このリポジトリの中身は、元のプロジェクトの `tools/build_site.sh` が作ったものです（直接は編集しない）。
